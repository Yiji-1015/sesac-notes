OpenCV 이미지 전처리: 잡음, 조명, 모양 다루기

모델 > 이미지

💡 한 문장으로

사진은 잡음, 고르지 않은 조명, 섞인 물체 때문에 그대로 쓰기 어려워요. OpenCV로 잡음을 줄이고, 물체와 배경을 나누고, 모양을 세고, 그림을 늘려요.

🤔 왜 필요할까?

모델에 사진을 넣기 전에, 사진은 대개 그대로 쓰기 어려운 상태예요. 이 한 장에 흔한 문제가 다 들어 있어요.

OpenCV는 그림을 숫자 배열로 다루는 라이브러리예요. 잡음을 줄이고, 물체와 배경을 나누고, 모양을 세고, 그림을 늘리는 전처리를 맡아요. 전처리를 잘하면 모델이 배울 것이 줄고, 모델 없이 규칙만으로 풀리는 문제도 많아요.

🗺️ 통째로 한 번

읽기 → 밝기와 색으로 고르기 → 잡음 줄이기 → 흑백 두 값으로 나누기 → 모양 다듬기 → 세기 → 늘리기. 상자를 누르면 그 단계로 가요.

🔎 한 단계씩: 설명과 코드를 나란히

코드의 ① 부분

① 그림 읽기

그림 파일을 (세로, 가로, 채널) 숫자 배열로 읽어요.

코드 읽기

코드뜻
cv2.imread(path)컬러 그림을 BGR 순서의 uint8(0~255) 배열로. 파일이 없으면 오류 대신 None을 돌려줘서 꼭 확인해요.
img[40, 40](세로 40, 가로 40) 자리의 픽셀. 좌표 순서가 (y, x)예요.
cv2.cvtColor(img, cv2.COLOR_BGR2RGB)채널 순서 바꾸기

이 단계까지 실행하면

코드의 ② 부분

② 밝기와 색으로 고르기

흑백으로 바꾸거나, HSV로 바꿔 특정 색 범위만 골라요.

HSV는 색을 색상(Hue, 무슨 색), 채도(Saturation, 얼마나 진한지), 밝기(Value)로 나눠요. 조명이 바뀌면 RGB 세 값이 다 바뀌지만, 색상은 비교적 그대로라 색으로 고르기 쉬워요.

코드 읽기

코드뜻
cv2.COLOR_BGR2GRAY밝기 하나로
cv2.COLOR_BGR2HSV색상, 채도, 밝기로. OpenCV의 색상은 0~179
cv2.inRange(hsv, low, high)세 값이 모두 범위 안이면 255, 아니면 0

이 단계까지 실행하면

코드의 ③ 부분

③ 잡음 줄이기

주변 픽셀을 보고 값을 고쳐서 튀는 점을 줄여요.

코드 읽기

코드뜻
cv2.GaussianBlur(gray, (5, 5), 0)5×5 주변의 가중 평균. 0이면 퍼짐 정도를 크기에 맞춰 자동
cv2.medianBlur(gray, 5)5×5 주변의 가운데 값
cv2.PSNR(a, b)두 그림이 얼마나 비슷한지 (dB). 클수록 비슷

이 단계까지 실행하면

코드의 ④ 부분

④ 이진화: 기준 하나 vs 자리마다 다른 기준

픽셀을 기준보다 밝으면 흰색, 어두우면 검은색으로 나눠요.

코드 읽기

코드뜻
cv2.threshold(..., cv2.THRESH_BINARY + cv2.THRESH_OTSU)Otsu가 그림 전체를 보고 두 무리를 가장 잘 나누는 기준을 하나 정해요. 앞 값이 그 기준
cv2.adaptiveThreshold(img, 255, GAUSSIAN_C, BINARY, 31, 5)자리마다 주변 31×31의 가중 평균에서 5를 뺀 값을 기준으로

이 단계까지 실행하면

코드의 ⑤ 부분

⑤ 형태학: 작은 점 지우고 구멍 메우기

흰 영역을 깎고 불리는 연산으로 마스크를 다듬어요.

코드 읽기

코드뜻
cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))깎고 불릴 때 쓸 5×5 원 모양
cv2.MORPH_OPEN열기 = 깎기 후 불리기. 깎을 때 사라진 작은 점은 다시 안 생겨요.
cv2.MORPH_CLOSE닫기 = 불리기 후 깎기. 불릴 때 메워진 작은 구멍은 다시 안 열려요.
cv2.connectedComponents(m)이어진 흰 덩어리 수 (배경 포함이라 1을 빼요)

이 단계까지 실행하면

코드의 ⑥ 부분

⑥ 물체 세고 모양 보기

흰 덩어리의 윤곽을 찾아, 위치, 넓이, 꼭짓점 수를 재요.

코드 읽기

코드뜻
cv2.findContours(m, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)바깥 윤곽만, 직선 구간은 끝점만 남겨서
cv2.boundingRect(c)윤곽을 감싸는 네모 (x, y, 가로, 세로)
cv2.approxPolyDP(c, 0.02 * 둘레, True)윤곽을 둘레의 2% 오차 안에서 꼭짓점이 적은 다각형으로 줄이기

이 단계까지 실행하면

코드의 ⑦ 부분

⑦ 증강: 같은 그림을 조금씩 바꿔 늘리기

뒤집기, 회전, 밝기 바꾸기로 학습용 그림을 늘려요.

코드 읽기

코드뜻
cv2.flip(img, 1)좌우 뒤집기 (0이면 상하)
cv2.getRotationMatrix2D(중심, 각도, 배율)회전을 나타내는 2×3 행렬
cv2.warpAffine(img, M, (가로, 세로), borderMode=BORDER_REFLECT)행렬대로 옮기고, 빈 가장자리는 거울처럼 채우기
cv2.convertScaleAbs(img, alpha=1.0, beta=40)모든 픽셀에 40을 더하고 0~255로 자르기

🛠️ 실제로 할 때

      
상황어떻게
어떤 잡음인지 먼저 본다점처럼 튀는 잡음은 Median, 고르게 자글자글한 잡음은 Gaussian이 잘 맞아요. 줄이면 선과 모서리도 같이 흐려지니 커널 크기를 작게 시작해요.
조명이 고르지 않다기준 하나(Otsu)는 조명을 갈라요. adaptive 이진화를 쓰거나, 배경을 크게 흐린 그림을 빼서 조명을 먼저 평평하게 해요.
모델에 넣을 그림크기를 맞추고(cv2.resize), BGR을 RGB로 바꾸고, 0~1이나 평균 0으로 맞춰요. 학습과 실제 사용에서 전처리가 똑같아야 해요.
영상cv2.VideoCapture로 한 장씩 꺼내 같은 전처리를 해요. 자세한 내용은 옛 Day13 노트를 보세요.
