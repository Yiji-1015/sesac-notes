평생 학습과 머신 언러닝: 잊지 않게, 잊게 하기

모델 > 추천과 평생 학습

💡 한 문장으로

새 일을 배우면 예전 일을 덮어써서 파국적으로 잊어요. 예전 데이터를 조금 섞거나(리플레이) 중요한 가중치를 묶으면(EWC) 덜 잊어요. 반대로 일부를 골라 잊게 할 때는 처음부터 다시 배운 모델을 정답으로 두고, 경사 상승이나 작업 벡터 빼기로 싸게 흉내 내요.

🤔 왜 필요할까?

모델은 한 번 배우고 끝나지 않아요. 새 데이터와 새 일이 계속 생기고(평생 학습, 지속 학습), 반대로 "제 데이터를 지워 주세요"처럼 배운 것의 일부를 없애야 할 때도 있어요(머신 언러닝). 둘 다 "처음부터 다시 학습"하면 정확하지만 큰 모델에서는 너무 비싸요.

평생 학습머신 언러닝
원하는 것새로 배우면서 예전 것은 지키기골라서 잊고 나머지는 지키기
어려운 점새 일을 배우면 예전 것을 덮어씀 (파국적 망각)안 보여 주기만으로는 잘 안 잊음, 잊었는지 확인도 어려움
정답 (비쌈)모든 데이터로 처음부터지울 데이터를 빼고 처음부터
이 쪽②~⑤⑥⑦

이 쪽은 작은 손글씨 숫자 모델로 두 문제를 직접 재현해요. 개인정보를 외운 LLM에서 그 정보만 지우거나, 자율주행 모델에 새 도시의 데이터를 더하는 일이 같은 문제의 큰 버전이에요.

🗺️ 통째로 한 번

두 가지 일 → 그냥 이어서 → 리플레이 → EWC → 비교 → 지워 달라는 요청 → 빠르게 잊기. 상자를 누르면 그 단계로 가요.

코드는 examples/continual/remember_forget.py 하나예요. 데이터는 scikit-learn에 들어 있어서 받을 파일이 없어요.

코드의 ④ 부분

④ 중요한 가중치는 덜 움직이게: EWC

일 A에서 가중치마다 중요도(Fisher 정보)를 재 두고, 일 B를 배울 때 중요한 가중치가 멀리 가면 벌점을 줘요.

모든 가중치가 일 A에 똑같이 중요하지는 않아요. 조금만 바꿔도 일 A의 출력이 크게 흔들리는 가중치가 중요한 거예요. 그 정도를 재는 게 Fisher 정보예요. 모델이 내는 분포에서 답을 뽑아 그 log 확률의 기울기를 제곱해 평균 내요.

EWC(Elastic Weight Consolidation)는 일 B의 손실에 λ/2 × Σ Fᵢ (θᵢ − θᵢ_A)²를 더해요. 중요한 가중치는 고무줄로 일 A 때 자리에 묶이고, 덜 중요한 가중치는 일 B를 위해 자유롭게 움직여요. 예전 데이터를 저장하지 않아도 되는 게 장점이에요.

이 밖에 예전 모델의 출력을 새 모델이 따라 하게 하는 LwF(모델 가볍게의 지식 정제와 같은 생각), 일마다 작은 전문가를 두고 입력에 따라 골라 쓰는 방법(전문가 혼합)도 있어요.

코드뜻

lam / 2 * Σ F × (θ − θ_A)²EWC 벌점: 중요한 가중치가 멀리 갈수록 커요

코드의 ⑥ 부분

⑥ 숫자 3을 지워 주세요: 처음부터 다시, 남은 것만 더

일 A 모델에서 숫자 3에 대한 지식만 없애요. 지울 데이터 없이 처음부터 다시 배운 모델을 정답으로 두고 비교해요.

개인정보 삭제 요청(잊힐 권리), 저작권 문제, 잘못된 데이터, 위험한 지식처럼 모델에서 일부를 빼야 할 때가 있어요. 확실한 방법은 지울 데이터를 빼고 처음부터 다시 배우는 거예요. 머신 언러닝의 목표는 이 모델과 구별되지 않는 모델을 훨씬 싸게 얻는 거예요.

잘 잊었는지는 세 가지로 봐요. 지울 데이터에서 성능이 다시 배운 모델만큼 떨어졌나, 나머지 성능은 지켰나, 그리고 모델의 반응으로 "이 데이터가 학습에 쓰였는지"를 알아낼 수 없나(멤버십 추론)예요. 여기서는 클래스 하나를 통째로 지워서 앞의 둘로 충분해요. 특정 사람의 몇 건만 지우는 경우는 성능 차이가 작아서 세 번째가 중요해져요.

코드의 ⑦ 부분

⑦ 빠르게 잊게 하기: 경사 상승과 작업 벡터 빼기

지울 데이터의 손실을 일부러 키우는 방법과, "지울 데이터 쪽으로 가는 가중치 방향"을 빼는 방법을 비교해요.

경사 상승: 지울 데이터에서는 손실을 줄이는 대신 키워요. 남길 데이터의 손실도 같이 줄여서 나머지가 무너지지 않게 잡아 줘요. LLM에서는 이걸 기본으로, 손실이 끝없이 커지지 않게 묶은 NPO 같은 변형을 써요.

작업 벡터 빼기: 지울 데이터만 더 배운 모델에서 원래 모델을 빼면 "그 지식 쪽으로 가는 방향"이 나와요(작업 벡터). 이걸 원래 모델에서 빼면 그 지식이 약해져요. 학습 없이 가중치 덧셈뿐이라 빠르고, 여러 설정으로 만든 작업 벡터들에서 부호가 같은 칸만 모아 빼면(NegMerge) 더 안정적이라는 연구도 있어요. LLM에서는 Fisher 정보로 지울 지식과 관련된 가중치만 골라 손대기도 해요.

🛠️ 실제로 할 때

      
상황어떻게
새 데이터가 계속 들어온다가장 먼저 리플레이를 써요. 예전 데이터 일부를 남기기 어렵다면 EWC 같은 규제나, 일마다 작은 어댑터(LoRA)를 따로 두는 방법을 봐요.
잊혀야 하는 데이터가 생겼다법적 요구라면 결국 다시 학습하는 게 가장 확실해요. 빠른 방법은 다시 학습할 때까지의 응급 처치로 쓰고, 지울 데이터, 남길 데이터, 멤버십 추론 셋으로 확인해요.
애초에 덜 외우게학습할 때 개인정보를 걸러내고, 중복을 없애고, 차분 프라이버시 같은 방법을 쓰면 나중에 지울 일이 줄어요.
