트리와 앙상블, 교차검증: 더 나은 모델을 믿을 만하게 고르기

모델 > 머신러닝 기초 2/3쪽  |  이전: 회귀와 분류  |  다음: 평가지표와 군집

💡 한 문장으로

트리는 예/아니오 질문을 이어 가며 판단하고, 여러 트리를 묶으면(앙상블) 더 안정돼요. 어느 모델이 나은지는 한 번이 아니라 교차검증으로 여러 번 재서 판단해요.

🤔 왜 필요할까?

1쪽에서는 선형 모델과 KNN을 valid 20건으로 비교했어요. 그런데 valid 한 번의 점수가 얼마나 믿을 만할까요? 1쪽의 모델과 이 쪽의 트리 모델들을 두 방법으로 재 봤어요.

🗺️ 통째로 한 번

트리 하나 → 트리 여럿의 투표(포레스트) → 틀린 걸 고쳐 가는 트리들(부스팅) → 어느 열을 썼나 → 믿을 만하게 재기. 상자를 누르면 그 단계로 가요.

1쪽의 코드(①~⑦)에 이어서 같은 파일이 자라요. 오른쪽 코드에서 1쪽 부분은 접혀 있어요.

🔎 한 단계씩: 설명과 코드를 나란히

트리는 사람이 읽을 수 있는 규칙을 만들어요. 그리고 숫자의 크기 차이에 영향을 받지 않아서 크기 맞추기가 필요 없어요 (scale=False).

🛠️ 실제로 할 때

      
상황어떻게
트리 깊이, 트리 개수는 어떻게 정하나후보 몇 개를 교차검증으로 비교해서 골라요 (GridSearchCV). test로 고르면 안 돼요.
부스팅이 늘 이기나표 데이터에서 자주 강하지만, 데이터가 적으면 과적합하기 쉬워요. 교차검증 흔들림을 같이 봐요.
중요도를 원인으로 읽고 싶다중요도는 서로 비슷한 열끼리 나눠 갖기도 해서, 원인 분석에는 따로 실험이 필요해요.
